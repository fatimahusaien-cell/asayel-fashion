# أصـايـل

موقع هبوط احترافي لعلامة أزياء فاخرة، مستوحى من أسلوب جلد الف��د والمنطقة العربية.

## التشغيل

- افتح ملف `index.html` مباشرة في المتصفح.
- أو استخدم خادم محلي بسيط مثل:

```bash
python -m http.server 8000
```

ثم افتح: `http://localhost:8000`

## الوصف

- هوية بصرية: أسود، بيج، ذهبي، وملمس جلد الفهد
- ترتيب الصفحة: هيرو، مجموعات، حرفية، مدونة، واتصال
- تصميم متجاوب ومناسب للموبايل
- أسلوب عربي أنيق مع ألوان فخمة
